# Delhi Wally — Pure Spices, True Flavors

Official web application for **Delhi Wally**, purveyors of 100% natural, unadulterated Indian spices (Red Chilli, Turmeric, Dhaniya, Jeera, and artisanal Garam Masala).

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org) (App Router, Turbopack)
- **UI & Styling**: [Tailwind CSS](https://tailwindcss.com), [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand)
- **Email & Communications**: [Resend](https://resend.com)
- **Deployment**: Netlify / Vercel

## Getting Started

First, install dependencies:

```bash
npm install
```

Configure environment variables:

```bash
cp .env.example .env.local
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## Production Build

To create an optimized production build:

```bash
npm run build
```

To run the production server:

```bash
npm run start
```
